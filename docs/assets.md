# Asset inventory

All visible images are local to `apps/storefront/public/images`; there are no runtime remote image dependencies.

- `products/*.webp`: photos from avinashdm/gs-images, quickcart directory, pinned source commit c28fcaee435099f4b42f481366c6e304c9c857b1. The descriptive filenames are mapped in seed.
- `products/*.svg`: original monitor, tablet, hair dryer, blender, speaker and coffee machine illustrations.
- `hero-phones.svg`: original four-device composition; a generic illustration, not an official Samsung/Apple product render.
- `blog-*.svg`: original editorial illustrations for sample articles.

Seed prices, ratings, product descriptions and banners are demo content. Reused imagery for variants is intentional for the starter catalog. For production, replace demo images with licensed SKU-specific media and verify specifications.
